Deep Learning · CV
Hierarchical Group Activity Recognition
PyTorch · CNN · LSTM · ResNet-50 · Spatial-Temporal
Reproduced & extended the CVPR 2016 paper on hierarchical deep temporal modelling. Two-stage LSTM architecture jointly models individual player actions and group-level activities in volleyball videos.
↑ 90.12% accuracy — surpassing original paper across all 8 baselines

Deep Learning · CV
Hierarchical Relational Networks for Activity Recognition & Retrieval
GNN · Relational Reasoning · Metric Learning · Video Retrieval
Implemented HRN (ECCV 2018) with fully-vectorised pairwise relational layers replacing O(K²) Python loops. Extended to activity retrieval using learned metric embedding spaces. Comprehensive 9-baseline ablation study.
↑ 89.10% accuracy with temporal LSTM extension
GitHub ECCV 2018
Deep Learning · Multimodal
Image Captioning with Transformers
CNN Encoder · Transformer Decoder · Cross-Attention · Beam Search
End-to-end image captioning system. ResNet-50 encoder extracts visual features; a 6-layer Transformer decoder with cross-attention generates fluent natural language descriptions. Trained on Flickr8k with BLEU evaluation and beam search decoding.
Corpus BLEU ~0.21–0.26 on Flickr8k test set

PyTorch · KNN · SMOTE · Scikit-learn · Neural Network
Hybrid anomaly detection pipeline combining KNN density scoring with a deep neural network classifier. Tackled severe class imbalance (<1% fraud rate) via SMOTE, class-weighted loss, and threshold calibration.

NYC Taxi Trip Duration Prediction
Ridge Regression · Feature Engineering · EDA · Scikit-learn
End-to-end regression pipeline on millions of NYC taxi records. Rich feature engineering: haversine distance, bearing angle, cyclical time encodings, and geospatial clusters. Log-transformed target, RMSLE optimisation.
